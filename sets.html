Set calculator.

Enter your sets, try an expression and check your working.

Your own set expression

Separate members with commas. Use integers or words such as red. Use {} for an empty set.

Fill in U when you use a complement or U itself. It should contain every member of your sets.

Set notation
∩
A n B · members in both sets
∪
A u B · members in either set
∖
A - B · members in A outside B
ᶜ
A' · members of U outside A
△
A ^ B · members in exactly one set

Try a longer expression

In A n (B u C), work out the brackets first. Complement comes next, then intersection and difference, then union and symmetric difference. Operations at the same level run from left to right.

You can also enter a set directly, for example A n {2, 4}.
